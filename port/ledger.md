# Port ledger

One row per unit of upstream (VS Code 1.147.0) that the native app must cover.
Status: `todo` (not started), `stub` (answers without the real behavior), `ported` (behavior written, upstream tests not all passing yet), `verified` (upstream tests or the named check pass), `removed` (left out by a product decision, see port/notes.md), `n/a` (upstream test infrastructure or Electron process/IPC/DOM layers the port replaces with its own checks or architecture).
Evidence names the narrowest check that can fail on the row. Rows are generated by `bun port/tools/gen-ledger.ts`; status and evidence are edited by hand and kept on rerun.
